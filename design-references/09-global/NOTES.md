# DevHub Global Colors Reference

## Use this reference for the global color system of DevHub.

### Goals
- Keep the overall feel premium, modern, dark, and polished.
- Use a developer-focused visual language.
- Preserve the strong dark base with neon-like accent energy.
- Build a clear, reusable global color system for the whole product.

### Brand direction
- Primary brand color: electric indigo / blue-violet.
- Secondary brand color: vivid purple.
- Accent color: orange / amber for highlights and CTA emphasis.
- Main background: deep navy / almost-black.
- Use subtle gradients and soft glows, not loud oversaturation.

### What this reference should inform
- Global colors page / design-system page.
- Primary, secondary, and accent palette.
- Neutral scale.
- Semantic colors (success, error, warning, info).
- Text hierarchy colors.
- Surface, card, input, border, and divider colors.
- Button and badge styling.
- Gradient usage for hero and highlighted elements.

### Style notes
- The page should feel structured like a design-system board.
- Cards should be clean, softly glowing, and neatly divided.
- Typography should remain crisp and premium.
- Use the color swatches and layout in `colors-reference.png` only as a reference, not as something to copy literally.
