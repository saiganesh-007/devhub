# DevHub App Shell Reference — Dashboard

Use `dashboard-reference.png` as the **layout-language reference** for the DevHub app shell.

## What to take from this reference

Use this reference mainly for:
- sidebar width and icon spacing
- topbar height and structure
- search bar placement
- page margins and card spacing
- card density and dashboard layout rhythm
- premium clean surface treatment
- chart/table/card composition

Do **not** copy the exact finance content.
Adapt the structure for DevHub.

## DevHub adaptation

This must become a GitHub / developer analytics product dashboard, not a finance dashboard.
Replace the finance-specific content with DevHub content such as:
- saved developers
- saved repositories
- search overview
- repository activity
- stars / forks / issues summaries
- language breakdown
- contributor insights
- recent comparisons
- recently viewed developers/repositories
- watchlist / favorites

## Theme requirement

Important: the product must support:
- Light mode
- Dark mode
- System mode

Do not build this as a dark-only dashboard.

### Theme behavior
- There should be a real theme setting in the app shell.
- System mode should follow the OS/browser theme.
- Dark and light themes should both feel premium.
- Colors, borders, shadows, card surfaces, charts, and text contrast must all adapt properly.
- No broken contrast in either mode.

## Visual direction

- clean and premium
- modern developer-tool UI
- refined and not childish
- card-based but not cluttered
- elegant spacing
- polished typography
- subtle, not noisy

## App shell expectations

The app shell should include:
- sidebar
- topbar
- theme toggle / theme setting
- user menu
- main content area
- responsive behavior

On smaller screens:
- sidebar may collapse
- layout should remain clean and usable

## Important rule

Use this image as a **layout and spacing reference**, not as a literal product template.
The finished dashboard must feel like DevHub.
