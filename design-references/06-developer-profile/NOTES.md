# DevHub Developer Profile Reference

Use `developer-reference.png` as the **developer profile page visual reference**.

## What to take from this reference

Use this mainly for:
- hero/profile-section composition
- balance between identity and metrics
- premium personal-brand presentation
- clean section grouping
- card spacing and visual hierarchy
- profile summary + stats + skills style
- strong first-screen impact

## What NOT to copy literally

Do not copy the exact person, exact text, or portfolio content.
This is only a **layout and presentation reference**.

## DevHub adaptation

This page must become a **GitHub developer intelligence profile page**.
Replace portfolio-specific content with DevHub developer data, such as:
- GitHub avatar
- display name
- username / handle
- bio
- location / company / website (when available)
- followers / following
- public repositories count
- total stars across tracked repos
- top repositories
- language breakdown
- pinned / featured repositories
- contribution or recent activity summary
- organizations
- saved/favorite action
- compare action

## Visual direction

- premium and polished
- developer-tool feel, not generic portfolio clone
- clean and modern
- slightly cinematic but still practical
- strong hero section without looking overdesigned
- elegant typography
- subtle gradients / glow are okay if refined

## Theme requirement

DevHub must support:
- Light mode
- Dark mode
- System mode

So this reference must be translated into a themeable product page.
Do not build dark-only.

## Interaction expectations

The developer page should support:
- responsive layout
- clear CTA actions (save, compare, open GitHub)
- tabs or sections if needed
- loading state / skeletons
- empty / error handling

## Product fit

This page should blend with the DevHub app shell, search experience, and overall premium GitHub analytics identity.
