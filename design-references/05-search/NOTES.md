# DevHub Search Reference

Use `search-reference.png` as the **primary visual reference for the DevHub search input style**.

## What to take from this reference

Use this image mainly for:
- the soft glass / neumorphic search field appearance
- the rounded elongated pill shape
- the clean minimal search affordance
- the premium subtle shadowing
- the separate rounded search action button on the right
- the calm spacious look

## What NOT to copy literally

Do not turn the full DevHub app into a blank pale mockup.
This is mainly a **search-bar reference**, not the full product-page layout.

## DevHub adaptation

Apply this reference to the DevHub search experience:
- global search bar
- developers search
- repositories search
- compare search inputs where relevant

Search should support:
- searching GitHub developers
- searching GitHub repositories
- filter / tabs if the product needs them
- loading state
- empty state
- error state
- recent searches or suggestions if implemented

## Theming requirement

Important: DevHub must support:
- Light mode
- Dark mode
- System mode

So this reference should be translated into both themes.

### Light mode
- preserve the soft premium look
- use subtle borders and shadows
- keep it clean, airy, and elegant

### Dark mode
- create an equivalent premium version
- do NOT just invert poorly
- keep contrast accessible
- search field should still feel polished and tactile

## Interaction expectations

The search field should feel premium and responsive:
- strong focus state
- smooth hover/focus transitions
- clear typing state
- keyboard accessible
- responsive on mobile

## Product fit

This search design should blend with the DevHub app shell and overall premium GitHub/developer-analytics identity.
